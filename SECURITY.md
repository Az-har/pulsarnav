# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes |
| < 1.0.0 | No                 |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in PulsarNav (e.g., in local file handling, BLE service isolation, intent filters, or encryption):

1. **Do not open a public issue.**
2. Report it privately via [GitHub Private Vulnerability Reporting](https://github.com/nikhilmaity00/pulsarnav/security/advisories/new).
3. Provide details on how to reproduce the vulnerability, including device environment and attack vectors.

Reports are reviewed promptly and fixes are published with priority in subsequent patch releases.
